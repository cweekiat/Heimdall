RF and electronic-warfare watch · free, open data

See interference through the receivers it disturbs.

Heimdall reads signals that aircraft, ships, amateur radio stations and satellites already broadcast. It looks for the ways those receivers degrade, rules out natural explanations, and raises alerts you can check line by line. Works anywhere in the world.

The band ladder

One watch, from HF to C-band.

No free source measures the spectrum directly. Each band is covered by receivers whose degradation can be observed. Every detector states its coverage and what it rules out first.

  1. 3–30 MHzHFWSPR and PSK Reporter spots: path fades far below the usual for that hourExperimental
  2. 156–162 MHzVHF marineShip AIS: spoofed positions, impossible speeds, dark gapsLive
  3. 1090 MHzL 1090Aircraft ADS-B from adsb.lol, adsb.fi and OpenSkyLive
  4. 1559–1610 MHzGNSS L1Aircraft position integrity: jamming cells with an emitter estimate, spoofing, a daily interference mapLive
  5. 1400–1427 MHzL 1.4 GHzSMAP interference flags and the CYGNSS noise floor, seen from orbitLive
  6. ~5.4 GHzC-band SARSentinel-1 radar interference annotationsConnector live

Context, never alerts on its own: FAA NOTAMs, NGA navigational warnings, space weather, weather, NASA FIRMS fires, CelesTrak orbits and GDELT. Emitter types are never attributed automatically.

How it works

Watch the receivers. Explain every alert.

Every alert carries its evidence

Rules that fired
Each value next to its threshold and its normal level, such as 58 % of aircraft degraded against an alert level of 10 %.
Natural explanations
Geomagnetic storms, solar flares, ducting and feed outages are checked first and lower confidence when present.
Cross-checks
Persistence over at least two windows, independent bands and an Admiralty grade. Missing evidence reads "Uncorroborated", never "False".
Analyst in control
Acknowledge, confirm, close as a false alarm or shelve. Verdicts feed threshold proposals; nothing changes on its own.

Real case, real data

Operation Midnight Hammer, 16–22 June 2025.

Replayed from public ADS-B archives. Of seven indicators in public reporting, five were visible in open data, and Heimdall raised surge, deployment and build-up alerts on its own.

  • Airlift wave across the Atlantic: seen
  • Tanker deployment to Europe: seen
  • Airborne command posts at strike time: seen
  • B-2 bombers: not visible, flew without broadcasting

Indicators show preparation, never a target or a strike.

Get started

Run it on your machine.

You need macOS or Linux, Python 3.12 with uv, and Node.js 20 or later. The demo needs no keys and no network.

  1. Clone the repository and install.
  2. Start the demo with synthetic data.
  3. Open http://127.0.0.1:8000.

For live monitoring, the offline basemap and optional API keys, follow the README.

Terminal
git clone https://github.com/cweekiat/Heimdall.git
cd Heimdall
uv sync
cd web && npm ci && npm run build && cd ..
uv run python -m heimdall.api.demo

Use it responsibly

Heimdall is for research and situational awareness on public data. Several sources, such as adsb.fi and some AIS feeds, allow personal, non-commercial use only; check each source's terms before you use its data. Alerts are leads to verify, not conclusions, and the tool never names a culprit or predicts a target.

Heimdall itself is released under the Heimdall Responsible Use License (Non-Commercial): free for study, research, teaching, journalism and public-interest work; no commercial use without permission, and never for jamming, spoofing, targeting people or attacks.
